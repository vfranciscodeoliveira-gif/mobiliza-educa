📷 Galeria de fotos • GitHub gratuito

As fotos são hospedadas no GitHub Pages. Primeiro envie os arquivos para a pasta do convite no GitHub; depois, informe aqui os nomes de cada arquivo. Nenhuma senha ou token GitHub é solicitado neste editor.

1. Abrir pasta das fotografias no GitHub

No GitHub, use Add file → Upload files, envie as fotografias JPG, PNG ou WebP e confirme em Commit changes. Se a pasta ainda não existir, use o link de instruções abaixo para criá-la.

Instruções e exemplos

Adicione até 12 imagens. Para evitar links incorretos, use exatamente o nome e a extensão do arquivo enviado. Uma foto escolhida como capa aparecerá no topo do convite depois da publicação.

💌 Confirmação por família e compartilhamento

Modo gratuito: o convidado preenche o nome e a quantidade de pessoas; o botão abre o WhatsApp com a mensagem pronta. A confirmação só é enviada quando ele confirmar no WhatsApp. Nenhuma resposta é gravada automaticamente no Firestore.

Ative a opção “Exibir aviso sobre confirmação de presença” na seção Publicação para liberar o formulário no convite público.

🎞️ Galeria animada

Os convidados também poderão navegar manualmente. O movimento respeita a preferência de acessibilidade do dispositivo.

Publicação e privacidade

Rascunhos só ficam disponíveis à conta administradora. Ao publicar, as fotos selecionadas e informações tornam-se públicas. O RSVP usa WhatsApp e não gera lista automática de presença. Não exiba dados fictícios de salão ou endereço antes da confirmação.
