# Fotografias da Lorena — hospedagem gratuita

Esta pasta hospeda imagens estáticas públicas do convite. O Firebase Storage não é necessário.

## Como enviar
1. Na página desta pasta no GitHub, selecione **Add file → Upload files**.
2. Envie fotografias JPG, PNG ou WebP com nomes simples, por exemplo `lorena-01.webp`, `lorena-02.webp`.
3. Confirme **Commit changes** na branch `main`.
4. Abra **Mobiliza Educa → Gestão Online → Convites Interativos → Administrar convite**.
5. Em **Galeria de fotos • GitHub gratuito**, digite `lorena-01.webp` e clique **Adicionar foto à galeria**.
6. Escolha a capa, confirme **Convite visível ao público** quando estiver pronto, e clique **Salvar**.

**Importante:** o editor só referencia fotos já enviadas. Ele NÃO envia imagens ao GitHub automaticamente. A remoção no editor não exclui o arquivo do repositório. Todas as fotos nessa pasta são públicas; não inclua imagens que devam permanecer privadas.

O salvamento de configurações utiliza o Firestore e exige as regras específicas `publicInvites` implantadas, além de conta proprietária ativa.
