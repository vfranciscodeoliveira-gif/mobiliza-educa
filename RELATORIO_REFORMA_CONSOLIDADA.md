# Mobiliza Educa — pacote unificado

Base: pacote único fornecido nesta conversa.

## Atualizações desta entrega
- Camada visual compartilhada para jogos: modal adaptável, leitura, foco visível, áreas de toque, responsividade e preferência por movimento reduzido.
- Desafio 60 Segundos: seleção conservadora de fotografias, com restrições adicionais para cenas específicas não representadas pelas imagens disponíveis.
- Tratamento de imagem indisponível: painel alternativo no próprio jogo.
- Preservados os arquivos de todos os módulos, gestão, testes e recursos da base.

## Limites verificados
Esta entrega **não** contém novas fotografias exclusivas para cada questão nem uma revisão pedagógica integral de todas as perguntas. Os módulos Milhão, Trilha, Memória e Cruzadas receberam a camada compartilhada, mas não foram reescritos internamente. Testes automatizados e inspeção visual em navegador são atividades distintas.
